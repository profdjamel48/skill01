# محاكيات علوم الطبيعة والحياة — دليل الاستخدام

## التثبيت
**Claude (claude.ai / التطبيق):** من إعدادات Claude افتح قسم المهارات (Skills) وارفع ملف `interactive-science-simulations.zip`. يجب أن يكون المجلد `interactive-science-simulations/` وبداخله `SKILL.md` في جذر الـ zip.

**Claude Code:** انسخ المجلد إلى `~/.claude/skills/interactive-science-simulations/` (للمستخدم) أو إلى `.claude/skills/` داخل المشروع.

## النطاق
المهارة مخصّصة **حصراً لمادة علوم الطبيعة والحياة (SVT)**: الأحياء وعلوم الأرض، وللاستخدام على الحاسوب فقط. لا تُستعمل لتجارب الفيزياء أو الكيمياء المحضة. عند فتح المحاكاة على شاشة عرضها 800px أو أقل، أو ارتفاعها 500px أو أقل، تظهر رسالة تطلب فتحها على الحاسوب بدلاً من المحاكاة.

## الاستخدام
اطلب مثلاً: «ابنِ محاكاة افتراضية لفحص خلايا البصل بالمجهر». تختار المهارة الأدوات والمراجع المنطبقة فقط، وتبدأ من `assets/starter-template.html`. الناتج ملف `index.html` مستقل بواجهة عربية (`lang="ar"`, `dir="rtl"`).

## محتويات حزمة المهارة
عند إنشاء `interactive-science-simulations.zip`، أدرج `SKILL.md` ومجلدي `assets/` و`references/` فقط. ملف **«معرض نماذج السكيل — interactive-science-simulations.html»** صفحة عرض تجريبية، وملف **«معاينة القالب — 20 خطوة.html»** اختبار مظهر للقائمة؛ كلاهما خارج المهارة ولا يُضمَّن في ملف ZIP.
