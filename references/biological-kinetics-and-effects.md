# الحركية الحيوية والمؤثرات المتحركة

اقرأ هذا المرجع فقط عندما تحتاج التجربة إلى تغير علمي مع الزمن، أو حركة مرئية مثل فقاعات أو دخان أو تموج سطح سائل. المؤثرات الزخرفية ليست محاكاة فيزيائية؛ لا تستخدمها بديلاً عن هدف بيولوجي أو نتيجة علمية صحيحة.

## 1. افصل النموذج العلمي عن الرسم

- خزّن الحالة العلمية بوحدات واضحة (مثل تركيز الركيزة والناتج والزمن)، واحسبها مستقلة عن مواضع الجسيمات أو الرسوم.
- اربط المؤثر المرئي بالحالة: عدد الفقاعات أو تواترها يتبع معدل التفاعل، وتغير اللون أو المنسوب يتبع القيمة المحسوبة.
- اذكر الافتراضات والوحدات، ولا تعرض قيماً تجريبية مختلقة كأنها قياسات حقيقية. إذا كانت المنحنيات توضيحية فسمّها كذلك.

## 2. مثال مبسّط لحركية الإنزيم

للتعليم عن السرعة الابتدائية يمكن استخدام نموذج Michaelis–Menten:

```js
function initialRate(substrate, vmax, km) {
  return vmax * substrate / (km + substrate);
}
```

`substrate` و`Km` لهما وحدة التركيز نفسها؛ و`vmax` و`initialRate` وحدة تركيز/زمن. عند ثبات الظروف، يتناسب `Vmax` مع تركيز الإنزيم، وتقترب السرعة من التشبع كلما زاد تركيز الركيزة.

إذا لزم تطور الركيزة مع الزمن، حدّث النموذج بخطوات زمنية صغيرة وثابتة، مع إبقاء التركيز غير سالب وحفظ المادة:

```js
function advanceReaction(state, dt, vmax, km) {
  var v = initialRate(state.substrate, vmax, km);
  var used = Math.min(state.substrate, v * dt);
  state.substrate -= used;
  state.product += used;
}
```

هذا تقريب تعليمي يفترض ثبات الظروف وعدم عكس التفاعل؛ لا تقدمه كنموذج عام لكل تفاعل. لمحاكاة تأثير الحرارة أو pH، استخدم بيانات موثوقة خاصة بالإنزيم أو وضّح أن المنحنى نوعي، ولا تفترض أن لكل الإنزيمات القيمة المثلى نفسها.

## 3. حركة مرئية خفيفة على Canvas

- استخدم جسيمات محدودة قابلة لإعادة الاستخدام للفقاعات أو الرذاذ أو الدخان؛ حدّث مواضعها وارسمها فقط أثناء الحركة.
- مثّل سطح الماء بتموج بسيط، لا بحل معادلات الموائع. لا توحِ بأن رسم اللهب أو الدخان يحاكي الاحتراق أو انتقال الحرارة فعلياً.
- اجعل معدل الجسيمات وسرعتها مرتبطين بالحالة أو بالحدث العلمي، لا بحلقة عشوائية غير محدودة.
- استخدم `requestAnimationFrame` مع زمن إطار (`dt`) محدود، وأوقف الرسم عندما لا توجد حركة. تجنب `setInterval` و`ctx.filter` و`shadowBlur` داخل الحلقة؛ راجع `performance-and-scaling.md`.
- احترم `prefers-reduced-motion` بخفض الحركة أو إيقافها مع إبقاء النتيجة العلمية ظاهرة. يجب أن يعيد `#rst` الحالة العلمية والجسيمات إلى قيم البداية.

هذه المؤثرات البصرية أداة شرح لتجربة SVT، وليست محرك فيزياء عامّاً أو بديلاً عن solver للسوائل أو الغازات.
