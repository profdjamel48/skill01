# معايير الرسم ومكتبة الأجهزة

الهدف: مظهر موحّد ورسوم علمية واضحة في ملف مستقل. استخدم وصفة الرسم و`Kit` بدلاً من إعادة رسم الأجهزة.

---

## 0. قبل البناء: اسأل المستخدم عن مصدر الرسوم (إلزامي)

اسأل عن مصدر الرسوم قبل البناء:

| الخيار | متى | ما تفعله |
|---|---|---|
| **أ. المكتبة المتجهية المدمجة** (الافتراضي والموصى به) | لا صور لدى المستخدم، أو يريد أخف ملف وأوضح تناسق | استخدم `Kit` من `assets/draw-kit.js` كما هو، وأضف أجهزة جديدة بالوصفة (§4) |
| **ب. لدي صور PNG مفرغة الخلفية** | المستخدم يملك صوراً بحقوق استخدام واضحة لهذه التجربة | استخدم الصور عبر `loadSprite` (§5) **مع رسم Kit بديلاً** إن فشل التحميل |
| **ج. مزيج** | صور لبعض الأجهزة فقط | صور للأجهزة المتوفرة، و`Kit` لباقي الأجهزة (والطاولة) |

لا تبحث عن صور على الإنترنت ولا تفترض أن للمستخدم صوراً. عند عدم الإجابة استخدم الخيار أ. افصل الرسم عن منطق التفاعل.

## 1. دستور المظهر

1. **اتجاه الضوء:** من **أعلى اليسار** دائماً. الظلال والغمق عند اليمين والأسفل.
2. **تدرج أسطواني للأجزاء المعتمدة:** غامق (يسار) ← لمعة (18%) ← عادي ← غامق (يمين). تُنجَز بـ `Kit.part`.
3. **زجاج = شفافية + حافة + لمعات تتبع شكله:** تعبئة شبه شفافة بتدرج أفقي، حافة `rgba(104,140,160,.95)` سُمكها 1.5–2، ولمعات مصممة باتجاه سطح الزجاج لا بخط مستقيم يُقصّ على حدوده. تُقص كل اللمعات داخل مسار الوعاء، ولا تُضاف لمعة طولية تلقائية إلا لنمط `vertical`. تستخدم `Kit.glass(g,path,x,y,w,h,{shine})`: يختار تلقائياً `ellipse` للأشكال العريضة والضحلة و`vertical` لغيرها؛ ويمكن تحديد `vertical` للأوعية القائمة، `horizontal` للشرائح، `diagonal` للأشكال المخروطية، `flask` لجسم الإرلنماير كي تتبع اللمعة كتفه وجانبيه المائلين، `ellipse` للأطباق والزجاجيات الدائرية/الضحلة، أو `none` لإخفاء اللمعة. لمسار الوعاء المفتوح، اترك خط الفوهة و`closePath()` خارج مسار الحدّ: `fill()` و`clip()` يغلقان المسار ضمنياً عند الحاجة، لكن `stroke()` لا يرسم خطاً يعبر الفوهة. ارسم حافة الفوهة الإهليلجية بشكل طبيعي، من دون نتوء شفة سكب أو شرطة منفصلة.
4. **فوهة الوعاء:** حافظ على الحد الإهليلجي المعتاد لفوهة الكأس والمخبار، ولا تضف شفة سكب بارزة أو شرطة منفصلة عند طرفها.
5. **سائل = أفتح في الوسط وأغمق عند الجدار** + سطح بيضاوي + خط تقوّس أبيض. تُنجَز بـ `Kit.liquid` مع قص بمسار الوعاء.
6. **ظل تماسّ** (`Kit.contactShadow`) تحت **كل** جهاز يقف على الطاولة، يُرسم أولاً.
7. **ممنوع:** مستطيلات مسطحة بلون واحد، حدود سوداء نقية `#000`، رسم الخطوط بدون تعبئة، سائل بلون مصمت، جهاز بلا ظل، ألوان خارج `Kit.pal`.
8. **لوحة الأجهزة:** عاجي `ivory` + جرافيت `graphite` للأجهزة، لون التمييز `#2f6f8f` للأزرار والشرائط، ودافئ `#b8503a` لعناصر مطاطية. ألوان السوائل المعلَّمة تُمرَّر كمصفوفة `[r,g,b]`.
9. **الطاولة:** `Kit.bench` فقط (جدار فاتح + سطح رمادي مخبري + لمعة حافة + ظل خفيف).

## 2. ترتيب طبقات الرسم

للجهاز المعقد: **ظل ← الجزء الخلفي ← الهيكل الرئيسي (بتدرج) ← الأجزاء الأمامية ← التفاصيل الدقيقة (تدريج، شاشات، مقابض مخرّشة) ← لمعات أخيرة.**
للزجاجيات: **فتحة خلفية ← سائل (مقصوص) ← جسم الزجاج + لمعاته ← حافة الفتحة ← التدريج.**

### 3.5 قواعد التركيب داخل المشهد

* **حامل الأنابيب:** يُرجع `Kit.tubeRack` مواضع الفتحات `slots` (نسبة إلى `cx`). ارسم الحامل، ثم الأنابيب عند `x = cx + slot*s` و`y = by - 14*s` (قاعدة الأنبوب على الرف السفلي)، ثم استدعِ `Kit.tubeRack(..., {front:true})` لرسم الحافة الأمامية للفتحات فوق الأنابيب.
* **الميزان:** ضع الكأس أو الوعاء عند مركز الكفة `(cx, by - 68*s)`.
* **جهاز الطرد:** أدِر الدوّار بتغيير `angle` في كل إطار أثناء `running`، وأظهر الأنابيب بـ`tubes:true` وهو مفتوح فقط.
* **الحمّام المائي:** ضع قواعد الأنابيب عند `y = by - 74*s`.
* **الحامل الرباعي:** الأداة المعلّقة تُرسم عند `(cx + 30*s, by + clampY*s)`.
* **مقياس الحرارة والمسبار:** يُغمَران بتمرير موضع الطرف داخل الوعاء، وترسم الوعاء **بعدهما** إن أردت أن يظهر الزجاج أمامهما.
* المجهر: اربط `focus` بالحلقة المنزلقة و`obj` ببرج العدسات (`bindRotary`). مجال الرؤية في optical-instruments.md.
* `Kit.bench(g,W,H,safeTop,edge)` — يملأ الطاولة ويُرجع `y` الحافة.

### 3.6 ما ليس في `Kit` بعد (أضفه بوصفة §4 عند الحاجة)

خلاط دوّامي (Vortex)، مطياف ضوئي، حوض الهجرة الكهربائية، جهاز PCR، أوتوكلاف، علبة رؤوس ماصات، كوفيت، خزانة تدفق رقائقي، ومجسّمات حيوية (قلب، جذع، عين). العيّنات الحيوية (بصلة، ورقة، جذر...) في `scientific-illustration-guide.md`.

## 4. إضافة جهاز غير موجود

1. حدّد الأصل والارتفاع التصميمي.
2. ارسم بوحدات تصميمية داخل `g.save(); g.translate(x,y); g.scale(s,s); … g.restore()`.
3. ابدأ بـ `Kit.contactShadow` إن كان واقفاً، ثم الأجزاء بـ `Kit.part`، والزجاج بـ `Kit.glass`، والسوائل بـ `Kit.liquid` (قصّ بمسار الوعاء).
4. أضف ثلاث تفاصيل مميزة على الأقل، مثل تدريج أو شاشة أو ملصق.
5. **لا تُعرّف ألواناً جديدة** إلا بإضافتها إلى `Kit.pal` أو تمريرها كخيار.
6. أضفه إلى الفهرس أعلاه وإلى `kit-preview.js`، ثم افحصه بصرياً (§6).
7. حافظ على النسب والأجزاء الأساسية للجهاز؛ فالمجهر مثلاً يحتاج قاعدة وذراعاً ورأساً وعينية وبرجاً وعدسات ومنصة ومشبكين ومكثفاً ومصباحاً ومقبضي بؤرة.

## 5. الصور مع بديل متجهي (الخيار ب/ج)

ضمّن PNG ذات قناة ألفا داخل الملف كـ`data:image/png;base64,...`:

```javascript
var sprites = {};
function loadSprite(id, src, anchor) {                 // anchor = {x,y} نقطة الأصل بنسبة 0..1 داخل الصورة
  var img = new Image();
  sprites[id] = { img: img, ok: false, ax: anchor.x, ay: anchor.y };
  img.onload  = function () { sprites[id].ok = true; invalidate(); };
  img.onerror = function () { sprites[id].ok = false; };   // يبقى البديل المتجه
  img.src = src;                                           // data URI فقط (لا روابط خارجية)
}
function drawDevice(g, id, x, y, s, vectorFallback, designH) {
  var sp = sprites[id];
  if (!sp || !sp.ok) { vectorFallback(g, x, y, s); return; }  // لا تُكسر المحاكاة بلا صورة
  var k = (designH * s) / sp.img.height;                       // اضبط الارتفاع التصميمي ثم U
  var w = sp.img.width * k, h = sp.img.height * k;
  g.drawImage(sp.img, x - w * sp.ax, y - h * sp.ay, w, h);
}
```
قواعد الصور: PNG شفافة بحجم يقارب ضعفي حجم العرض، لا تتجاوز 150KB للصورة أو 600KB إجمالاً. طابق الضوء أعلى اليسار، وأضف ظل تماس وبديل `Kit`، ولا تربط الصورة بمنطق التفاعل. ضع بيانات `ASSETS` في آخر الملف، وتأكد من حقوق الاستخدام.

## 6. المراجعة البصرية

عند إضافة جهاز أو تعديل `Kit`، شغّل `assets/kit-preview.js` (يتطلب `@napi-rs/canvas`) وافحص الأوراق الثلاث بصرياً. إذا تعذّر ذلك، اعرض الرسوم عبر Chromium/Playwright والتقط صورة. تحقق أن الجهاز معروف الشكل، وأن الزجاج والظلال والتدريج واتجاه الضوء متسقة، ثم عدّل أي خلل.

### أمثلة: ماذا يُعدّ سيئاً وماذا يُعدّ جيداً (المجهر)
* **سيئ:** مستطيل قاعدة + مستطيل عمود + دائرة للمنصة بألوان مسطحة، بلا ظل ولا عدسات ولا مقابض.
* **جيد:** قاعدة مستديرة بلمعة وقدمين، ذراع منحنٍ بتدرج، رأس بأنبوب عينية مائل، برج بثلاث عدسات ملونة الحلقات (الفعّالة أمامية)، منصة بمشبكين وآلية، مكثف ومصباح متوهج، مقبض بؤرة مخرّش يدور، وظل تماس.
